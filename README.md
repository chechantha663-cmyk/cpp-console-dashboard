# 🖥️ C++ Console Authentication & Utilities Dashboard

A structured C++ console application implementing user authentication, mathematical tools, and algorithmic pattern generation. Designed with clean code principles, modular functions, and robust input validation.

---

## 🌟 Key Features

- **🔐 User Authentication System:** Secure credential verification with predefined constants and controlled session handling.
- **🧮 Interactive Calculator:** Multi-operation math tool (+, -, *, /) equipped with divide-by-zero protection.
- **✖️ Multiplication Table Generator:** Automated table calculation from 1 to 10 for any given integer using loops.
- **⭐ Dynamic Pattern Generator:** Nested loop algorithms rendering customizable star-triangle patterns based on user input.
- **🔄 Modular Flow Control:** Replaced unstructured `goto` jumps with structured `while` / `do-while` control loops.

---

## 🛠️ Built With

- **Language:** C++ (C++11 or higher)
- **Standard Libraries:** `<iostream>`, `<string>`, `<cstdlib>`
